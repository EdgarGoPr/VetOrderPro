# Regla de Push Obligatorio

En este proyecto (VetOrder Pro):
- Cada modificación de código, corrección de bugs o agregado de funcionalidad debe finalizar con:
  1. `git add -A`
  2. `git commit -m "<mensaje descriptivo>"`
  3. `git push origin main`
- El remoto configurado es `git@github.com:EdgarGoPr/VetOrderPro.git`.

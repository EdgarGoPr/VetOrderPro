# Reglas de Proyecto - VetOrder Pro

## Política de Git y Despliegue
- Cada cambio o conjunto de modificaciones que se realice en el código debe ir acompañado obligatoriamente de un `git add`, `git commit` con mensaje claro y descriptivo en español, y un `git push origin main` al repositorio remoto (`git@github.com:EdgarGoPr/VetOrderPro.git`).
- Verificar que el proyecto compile con `cmd /c npm run build` antes de realizar el commit y push.
